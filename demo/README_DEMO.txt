AI-PromPlatform · демо узла НТС-1 с локальной моделью

ЗАПУСК
1. Убедись, что Ollama запущена (значок в трее). Если нет — открой приложение Ollama.
2. Двойной клик по START_NTS.bat.
   Откроется чёрное окно сервера и браузер со схемой (http://127.0.0.1:8765).
3. В правом верхнем углу чата должно быть: «Qwen2.5-7B · локально».
   Если написано «шаблоны» — Ollama не запущена; страница всё равно работает на шаблонных ответах.
4. Первый ответ модели может идти 10–30 секунд (модель грузится в память), дальше быстрее.

ЧТО ПРОВЕРИТЬ
- Нажми на датчик VT-101, затем «Спросить ИИ про VT-101».
- Кнопки «Сводка», «Почему унос?», «Что делать?».
- Сценарий «Износ подшипника К-101», скорость ×1: ИИ сам напишет предупреждение.
- В окне сервера видно каждый запрос: [OK] — ответ модели, [ШАБЛОН] — сработала защита или модель недоступна.

ДЛЯ ВИДЕО
Все вопросы и ответы модели сохраняются в llm_log.json в этой папке.
Прогони сценарии «Износ подшипника К-101» и «Дрейф FT-101» и задай пару вопросов в чате —
этот журнал нужен для монтажа: в видео будут настоящие ответы твоей Qwen.

ОСТАНОВКА
Закрой чёрное окно сервера.

Файл nts_hmi.html можно открыть и без сервера (двойным кликом) — тогда ИИ отвечает шаблонами.
